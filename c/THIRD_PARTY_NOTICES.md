# Third-party notices

The Human Calc C library (`c/`) contains code from the projects below. An application that
ships the library in binary form (the Windows and iOS apps, a shared library for Python) should
ship this file, or an acknowledgements entry made from it: PCRE2's license requires its notice
in the documentation of a binary redistribution. The other entries impose no condition on
binaries and are listed for completeness. Versions, sources and file lists are in each
library's `third_party/<lib>/VENDOR.md`.

| Component | License | Binary redistribution |
|---|---|---|
| libtommath 1.3.0 | The LibTom license (Unlicense) | no condition |
| PCRE2 10.49 (no JIT) | BSD-3-Clause WITH PCRE2-exception | reproduce the notice below |
| Ryu (d2s only) | Boost Software License 1.0 (chosen of Apache-2.0 OR BSL-1.0) | no condition (source copies keep the notice) |
| Unicode Character Database data in `src/gen/gen_unicode.c` (via Python's `unicodedata`, Unicode 15.0) | Unicode License v3 | the notice below, with the data or in its documentation |

The engine also reproduces the behavior of a few CPython functions (float remainder and power,
`round`, `timedelta`, true division, the final-sigma rule). Those parts are written from
Python's documented behavior and tested against Python's results; no CPython source is copied
or translated, so the PSF license does not apply (DESIGN.md 4.3).
